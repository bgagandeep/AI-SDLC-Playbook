# AI Governance

Starter artifacts for AI-system inventory, model inventory, risk register, data classification, evaluation policy, human oversight, and incident response. Validate them with `python3 scripts/check_governance.py`.

An empty inventory is valid only with a factual `not_applicable_reason`. Do not create placeholder systems or models to satisfy validation.

These artifacts support an ISO/IEC 42001-aligned operating model; certification requires organization-specific assessment and evidence.
